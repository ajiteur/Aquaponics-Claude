# Research reports and prompts

Where every research file lives. Source evidence, not canon: facts move into `data/knowledge/**` only as reviewed candidates.

- `research_reports/raw/`: original PDFs (corroboration reports, trust policy, MIDH 2025).
- `research_reports/markdown/`: full deep research reports as markdown.
- `research_reports/distilled/`: distilled packs used to seed canon.
- `research_reports/notes/<report title>/`: the researchers' working notes behind a report.
- `research_prompts/`: ready-to-paste deep research prompts.
